# Windows 11 — веб-симуляция

Интерактивная симуляция рабочего стола Windows 11, полностью в браузере. Без сборки и зависимостей — чистые HTML, CSS и JavaScript.

## Возможности

- Рабочий стол с иконками приложений (двойной клик — запуск)
- Панель задач с кнопкой «Пуск», закреплёнными приложениями и часами
- Меню «Пуск» с поиском, плитками приложений и кнопкой питания
- Перетаскиваемые окна: свернуть, развернуть, закрыть
- Приложения: Проводник, Блокнот, Калькулятор (работает), Параметры, Браузер (демо)

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages:
Settings → Pages → Source: Deploy from a branch → main / (root) → Save.

Сайт будет доступен по адресу `https://hhhvvv2219-cpu.github.io/windows11-web/`.

## Структура

- `index.html` — разметка рабочего стола
- `style.css` — оформление в стиле Windows 11
- `app.js` — логика окон, меню Пуск, приложений и часов
